OpenTubeX SideStore repository

Install the iPhone and iPad app from the official OpenTubeX source. Browse stable and nightly releases in SideStore and install updates from the same place.

Add the repository

  1. Set up SideStore on your iPhone or iPad.
  2. Scan the QR code, or use the button below on your device.
  3. Choose OpenTubeX or OpenTubeX Nightly and install it.
Add to SideStore

Manual setup

In SideStore, open Browse → Sources → + and paste this address:

https://sidestore.opentubex.org/source.json

Two apps, two channels

OpenTubeX

Stable beta releases. Choose this channel for everyday use.

Stable-only source

OpenTubeX Nightly

The latest development builds. Try new changes as they land.

Nightly-only source

Both channels install as separate apps with their own settings and libraries. You can keep both on the same device.

The main source includes both apps. Use a channel-only source if you prefer to see just one.

Requirements

iOS or iPadOS 17.4 or newer is required. The iPhone and iPad port is experimental.

SideStore signs the app with your Apple Account. With a free account, refresh SideStore and OpenTubeX within seven days. SideStore and both OpenTubeX apps together use the three active app slots available to a free account.
